Read before installing

Compatibility

Only HP PCI subsystem 103C:8C78, Intel macOS with Darwin 25.5–25.99, and the exact tested OpenCore 1.0.8 binary are accepted. BIOS F.15 is tested but not programmatically verified. The OpenCore SHA-256 is 1569cd1d183c5ee9fda2eced767a4b2efa307e6edfcf2a50109c9657098671ff. Other builds require manual installation with their matching validator.

Mount the actual boot EFI first. Exactly one mounted EFI/OC is required. The installer cannot prove an EFI is your boot target; you must identify it. It does not mount partitions or install OpenCore.

Changes and backup

The package installs /Applications/OmenControl.app and supporting documentation/tools in /Library/Application Support/OMEN Control. It changes only OmenFanBridge.kext and its Kernel/Add entry in the mounted EFI; it preserves other config values, graphics drivers, SMBIOS, serials and boot arguments.

A complete EFI copy with SHA-256 verification is saved under /Library/Application Support/OMEN Control/Backups before driver changes. These backups are private and require administrator access. Keep an independent bootable recovery USB.

Risks and limitations

Kernel/EFI changes can cause boot failure, crashes, sleep/wake problems or data loss. Fan control can cause overheating or throttling if firmware behavior differs. Monitor first use while attended. Automated rollback handles ordinary commit/validation errors, but cannot guarantee recovery from power loss or storage failure. If installation fails, inspect the Installer log and verify the EFI before rebooting. The new app may remain installed after an EFI rollback.

0% returns that fan to firmware Auto; it does not stop it. Low manual requests clamp to firmware minimums. RPM is measured in 100-RPM increments. GPU temperature may be unavailable; curves require both chip temperatures. Performance means full fans, not higher CPU/GPU power limits.

The unsigned first package/ad-hoc app may be blocked by macOS. It does not disable SIP, Gatekeeper or SecureBootModel. It is not a universal OMEN driver, and the full package/reboot workflow has not yet been hardware acceptance-tested.

Power access

Low Power Mode uses the app’s embedded on-demand helper. Open Settings and enable power access explicitly; macOS may ask for administrator approval. Ordinary fan requests and saved fan profiles do not prompt for a password.

After installation and recovery

Restart to load the bridge. Quiet login is configured for the current desktop user unless previously disabled. Check RPM, Auto, manual profiles, service off/on, sleep/wake and thermal behavior. Documentation includes recovery and manual-uninstall steps.

For recovery, boot your recovery USB, mount the correct EFI and restore the previous bridge and config from the verified backup. Validate using the matching OpenCore ocvalidate before rebooting. Removing only the app leaves the EFI kext installed.
