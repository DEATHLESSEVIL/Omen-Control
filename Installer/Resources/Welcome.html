Omen Control Alpha 1.0V

Experimental app and fan-bridge installer for the tested HP OMEN 16-wf1xxx, physical board 8C78, BIOS F.15.

Installs the app, OmenFanBridge 0.4.0, quiet login setup and documentation. A restart is required.

Before continuing: prepare a bootable recovery USB, mount only the intended OpenCore EFI, and quit OMEN Control. Read the next page for compatibility, backup and recovery requirements.

This is a community project, not an HP product. This first package is unsigned and is not Apple-notarized. End-to-end package installation/reboot testing is still outstanding.
